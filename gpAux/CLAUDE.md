# gpAux/ — Greenplum Auxiliary Components

Supporting infrastructure for Greenplum/Cloudberry.

## Contents

- **BUILD_INSTRUCTIONS** — Build documentation.
- **Makefile** — Orchestrates third-party dependency builds.
- **gpdemo/** — Demo cluster creation scripts (for development/testing).
- **client/** — Client tool packaging.
- **extensions/** — Additional extension build coordination.

Primarily used during development for setting up demo clusters (`gpdemo`) and managing third-party libraries.
