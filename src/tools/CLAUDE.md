# src/tools/ — Developer Tools

25 files of code analysis and build utilities for PostgreSQL development.

## Contents

- **ctags/etags generators** — Tag file creation for editor navigation.
- **codelines** — Code statistics.
- **pgindent** / **pgperltidy** — Code formatting tools.
- **check_keywords** — Validate keyword lists match the parser.
- **find_typedef** — Detect typedefs for pgindent.
- **copyright** — Copyright header management.
- **gen_keywordlist.pl** — Generate keyword lookup tables.
- **PerfectHash.pm** — Perl module for perfect hash generation.

These are development-time tools, not installed with the database.
