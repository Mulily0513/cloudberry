# src/template/ — Platform Configuration Templates

11 platform-specific files used by `configure` to set compiler flags and OS-specific settings.

Supported platforms: AIX, Cygwin, Darwin (macOS), FreeBSD, HP-UX, Linux, NetBSD, OpenBSD, OSF, Solaris, Windows.

Each file sets variables like `CFLAGS_SL`, `DLSUFFIX`, and other platform-specific build parameters.
